要約

戯曲『嘘と幻の手順』において、登場人物たちが交わす会話は極めて抑制され淡々としていますが、出現する語彙の頻度と周囲に引き連れるキーワード群は、劇の進行（全7フェーズ）に伴って鮮やかに変遷します。
最多出現語である「時間」「攻撃」「本当」「サーバ」「言葉」「人間」「汚染」を軸に、言葉の書き換え（リフレーミング）を通じてディストピア社会の構造とシステムの自壊がどのように言語化されているかを分析します。

『嘘と幻の手順』語彙の推移と構造分析

1. 基幹語彙の出現頻度

作品全体を通じて最も多く出現する基幹語彙は以下の通りです。

  • 時間（46回）
  • 攻撃（35回）
  • 本当（31回）
  • サーバ（25回）
  • 言葉（25回）
  • 人間（23回）
  • 汚染（22回）

これらの語彙は単調に反復されるのではなく、各場面で周囲に引き連れる共起語や文脈を劇的に変化させながら、密室の力学と見えないインフラ崩壊のサスペンスを推進していきます。

2. 展開に沿った頻出語彙の推移（全7フェーズ）

3. 物語構造を浮かび上がらせる「語彙の変容（リフレーミング）」

単なる話題の移動だけでなく、同じ事象を指す言葉が劇中で書き換えられていく推移が、ディストピア社会の言語統制と本作の構造を鮮明に浮かび上がらせています。

① 権力と手続きの言い換え

「拘束」 → 「同行」 → 「保護」 → 「非公式な同行」 → 「イレギュラー／アノマリー」

  • 序盤（p.7〜9）: Ａが突きつける生々しい権力行使の言葉「拘束」を、調査側は「同行」「安全（保護）」という官僚的レトリックに脱色・偽装しようとします。
  • 終盤（p.61）: 通信障害が不可逆となり事態が破綻すると、１〜４はＡの連行を「非公式な同行」と認め、さらにＡの存在を犯人ですらなく、システムが処理しきれなかった統計上の異常値＝「イレギュラー」「アノマリー」という無機質なシステム用語へと着地させます。国家の暴力性が最終的にシステムのエラーログとして処理されるプロセスです。

② 監視の内面化

「密告」 → 「報告」

  • 第5フェーズ（p.43）において、Ａは「誰も脱落せず、密告もなく進行する」と述べた直後、次のように自ら訂正します。

    「もう、言葉の中に組み込まれてしまっている。密告とは言わなくなった。報告ですよね」

  • 後半（p.58）で語られる「禁止されたのは言葉じゃない。禁止は、言葉が消えた後」という社会状況の通り、市民同士の相互監視が息を吸うような「日常の手続き（報告）」として自然言語に同化してしまったディストピアの現実を象徴しています。

③ 「時間」と「朝」の3段階の変質

作品中最頻出の「時間（46回）」と、冒頭から執拗に繰り返される「朝」は、劇中で質的な転換を遂げます。

  1. 第1段階：身体的・閉所感覚としての時間（p.5〜11）
    窓のない密室に夜通し留め置かれた人間の「いつ朝になったんだ」「誰の朝か」という、身体が直接感じる時間の喪失。
  2. 第2段階：システム論的・客観的時間（p.24〜27, p.40〜46）
    NTPサーバの同期ロジックにおける「5分の齟齬」、認証のタイムスタンプ、そして攻撃準備に費やされた「半年という時間」「300回のログイン」。人間から切り離されたマシンの時間。
  3. 第3段階：社会規範の崩壊と基準時の消滅（p.56〜63）
    市民の目覚めを管理する街頭チャイムの「朝」が、停電とサイレンによって「いつもと同じ朝ではない」へと反転。NTPのパニック閾値である「16分の誤差」によって社会全体の基準時計が消滅し、システムが自滅します。

④ 「多数決」の反転（社会規範からシステムの自壊へ）

  • 中盤（p.31）: Ａが「ネットワーク全体の時間を正しく保つための多数決の仕組みが悪用されるなんて」と皮肉を口にします。
  • 第5フェーズ（p.47）: ２との対話で「それぞれのサーバが自分が多数派だと、間違った認識を持っている」と、多数決の論理的脆弱性が語られます。
  • 終幕（p.63）:

    １「多数決は、」
    Ａ「多数決は、」
    ４「多数が矛盾する。」
    Ａ「多数決は破綻する。」

  • 誰もが規範（多数派の正しさ）に従うことで維持されてきたディストピア社会が、「多数派の自己確信」を突かれたことで一斉に破綻するという、劇全体の主題が語彙の収束として結実します。

⑤ 感覚・比喩の語彙群の不発

劇中で唯一、具体的・感覚的な手触りを持つ語彙群が登場しますが、そのすべてがＡによって冷徹に無効化されます。

  • コーヒー（玉子サンド）（p.11〜15）: 「死刑囚の最後の食事」「記号」「ゲームを中断しないための食事」。
  • 希望（羽・パンくず・香り）（p.50〜51）: ３が人間的な共感を求めて持ち出したエミリー・ディキンソンの詩を、Ａは「都合のいい幻」「たださまよって飢えて死ぬ」と一蹴。
  • マスタードの味（p.54）: ４が語る「見た目からは想像できないマスタード」に対し、Ａは「ちょっとコーヒーの香りがするくらいで、苦味も酸味もない」と感覚の共有を拒絶。

詩情や五感を通じた「人間的連帯」の回路が永久に閉じていることが、語彙の処理（トランザクション）のレベルで徹底的に証明されます。

4. 語彙の推移が立ち上げる「態度派」の劇空間

この語彙の推移は、演出および俳優の演技法（態度派）とも密接に結びついています。

  1. 台詞が意味を運ぶのではなく、語彙の配置が思考を露呈させる
    俳優は台詞に感情を込めて観客を説得するのではなく、各フェーズで支配的な語彙（パケット）をフラットに空間へ投げ入れます。
  2. 語彙の転換点が身体的構えの転換点になる
    「拘束」から「仮説」へ、「神通力」から「0.8の300乗」へ、そして「ディキンソンの詩」から「多数決の破綻」へ。語彙がスライドする瞬間こそが、俳優同士の距離感や沈黙（排気音）の密度が変化する真の転換点となります。
