要約

戯曲『嘘と幻の手順』における語彙の推移（全7フェーズ）は、単一のドラマ的プロットではなく、「5つの独立した機能的声部（ヴォイス）が織りなす対位法（フーガ）」として計画されている。
一般に「言語の直列処理の限界（同時発話＝カオス）」と片付けられる課題に対し、「独立した思考と個体性を持つ身体が発する声は、同時発話であっても観客に聞き分けられる」という態度派のスタンスを提示。
作中のフェーズ⑦において、完全な「ストレット（追迫）」や「主調回帰なき自壊（特等席）」に至る劇構造を持つ。

1. 態度派の身体と「縦の成立」 ――同時発話はなぜカオスにならないのか

音楽における対位法の最大の制約は、「横のメロディの自立性」を保ちながら、ある瞬間における「縦の響き（和声）」が協和音または厳密な不協和音解決規則を満たさなければならない点にある。

一般的な言語学や音響理論において、「言語は直列処理（一度に1つの情報しか受容できない）しかできず、複数の人間が同時に喋れば周波数がマスキングされ、単なる聴取不能な騒音（カオス）になる」と言われる。
しかし、態度派の演劇実践は、この「直列処理の限界」を身体の規律によって回避する。

① 個体性と独立した思考による「聞き分け」の成立

従来の感情過多な演劇において、俳優たちが大声で感情をぶつけ合って同時に発話すれば、それは確かに単なるセリフのぶつけ合いとなり、場は崩壊する。
しかし態度派において、俳優は以下の規律を保持する。
* ニュートラルポジションと呼吸排気: 感情を乗せるのではなく、呼吸器を制御し、空間の気圧に合わせてフラットに音声を排気する（身体訓練・音声訓練 参照）。
* 機能的態度（Adult状態）: 相手を感情的に屈服させるのではなく、客観的な情報パケットとして台詞を配置する。
* 独立した思考の結果としての発声: 相手の台詞に反射的に反応するのではなく、自らの内的なタスク・思考の帰結として言葉を身体から立ち上げる。
* 反応しているということは、発してもいるという自覚: 反応しか存在しないのであれば、自分自身も反応の手がかりになるものを発している筈。なにを読み取られるのかを意識する。

このように、役者一人ひとりが固有の骨格・声質・呼吸圧、そして空間に対する明確な思考のベクトル（個体性）を保持している場合、仮に発話のタイミングが完全に一致したとしても、観客はそれを混ざり合わない別々の旋律線として明瞭に「聞き分ける」ことが可能になる。

② 和声（ハーモニー）の代替としての「立体的知覚」

言語劇には、音楽のような「3度や5度の協和音」は存在しない。
しかし、自立した複数の身体から放たれる「独立した思考のライン」が同時に空間を満たすとき、観客の脳内には単なるテキストの意味を超えた「多層的な状況の立体的知覚」が立ち上がる。これを、態度派が舞台上で実現する「演劇における真の縦の対位法」と見立てる。

2. 登場人物の音響的・機能的定義（5つの自立声部）

登場人物（Ａ、１〜４）は、感情や人格を主張する主役／脇役（ホモフォニー）ではなく、それぞれが固有の周波数とタスクを帯びた「自立した5つの機能的声部（ヴォイス）」と見る。

【Ａ】基底接地線（Ground / Cantus Firmus）

  • 音響的特性：他者の入力を一切増幅せず、平熱のまま反射・無効化する硬質な基底。
  • 内包される多重イメージ：
  • 「神通力」の戒律を抱くリアリスト：技術を目的化せず、単なる日々の労働（手順）と割り切る平熱の姿勢。「奇跡（攻撃）を見せつければ見せつけるほど、大衆は防衛に走り、本質的な解放（解脱）から遠ざかる」という近現代史への諦念（『神通力』と統計的作為 参照）。
  • 統計上の特異点（アノマリー）：汚染された環境下で「泥を踏まなかった（$0.8^{300}$）」という、作為的なまでの完全無傷ゆえに捕らえられた逆説的存在。

【１】主幹走査線（Kernel Executive / 主導声部）

  • 音響的特性：極小の語彙（「まだ居てもらいます」「連想は無意味」）によって場を固定し、プロセスの保留を確定させる中枢（１の存在と語彙の重力 参照）。
  • 同時に成立可能な4つの進行モデル（重層的解釈）：
  • アルゴリズム執行モデル：感情を完全に排したOSカーネル。Ａを例外処理待ちのプロセスとして淡々とホールドする。
  • 官僚機構隠蔽モデル：事態の露見を恐れ、「非公式な同行」「盗聴のない盲点」という脱色語彙でＡに落としどころを呑ませようとする政治的隠蔽工作。
  • 鏡像的共犯・観測者モデル：自らも社会の空虚さを知っており、唯一言葉の通じるＡと共に「この世界がどう自壊するか」を言語化して見届けようとする共犯的観察者。
  • 心理的浸透圧モデル：平熱な礼儀正しさ（「コーヒーだけでも」）の裏に「死刑」「責任」を微量に注入し、ミリ単位で心理的探り合いを仕掛ける尋問官。

【２】計時パルス（Auditing Pulse / 定量走査声部）

  • 音響的特性：感情を交えず、「半年」「300回」「$0.8^{300}$」を等間隔で打ち込む冷徹な計時音。
  • 内包される迷宮（挫折の構造）：
  • 「数字の神通力」への眩惑：$0.8^{300}$ という統計的作為（奇跡）に魅入られた結果、周到な手段の巨大さに囚われ、追う側の自分自身が「事件の実像（真の目的）」を見失い迷宮化する。
  • 二元論への逃避と破綻：「最後はコインの表裏」という安易な二元論に逃げようとするが、Ａの「そのコインは誰のコインか」という問いによって一瞬で足場を崩される。

【３】境界往還系（Resonant Interface / 外部往還声部）

  • 音響的特性：密室と外部空間を物理的に往還（I/O）し、空間に異質なコードを投じる揺らぎ。
  • 内包される4つの非・弱さ解釈（４による即時継承が証明する事実）：
  • 思想的プローブ（リトマス試験紙）：無目的の攻撃に対し、「見返り（パンくず）を求めない無償の希望」というテストパターンを投げ込み、Ａがロマン主義的自己犠牲者かを測定する冷徹な尋問プロトコル（『パンくず』の継承と目的の死 参照）。
  • 管理社会の公的規範（スローガン）：「見返りを求めず体制に奉仕せよ」という、社会全体に刷り込まれた公式ドグマの反射的発露。
  • 監視者自身のメランコリー：自らも正当な見返り（パンくず＝個人の生）を得られず、目的の失われたシステムを保守させられている労働者としての絶望の波長。
  • 接続テストの無効化：最も機能しない言葉（詩）を投げ、それが無残に破棄されるプロセスを通じて「連帯の完全な死滅」を空間に証明する機能。

【４】規範グリッド（Structural Profiler / 枠組敷設声部）

  • 音響的特性：３の詩を寸分違わず引き受け、「パンくず」から「マスタード」「悪役の不在」へと跳躍する哲学的変転声部。
  • ２との不意の同期と対照的差異：
  • 同期：２の追及を聞いていないにもかかわらず、「周到な手段の裏にあるはずの目的が見えない」という《目的の真空》に全く同じ形で突き当たる。
  • 差異：２が数字と物理的時間（定量的）から迫り「計算の機能不全」に陥ったのに対し、４は物語・悪役・ロマン（定性的）から迫り、「社会から目的が死滅したことへの実存的戦慄」に到達する。たまごサンドのマスタード（不可視の固有感覚）を差し出し、Ａと共犯的な認識を結ぼうとする。

3. フーガ技法との厳密な照合 ――成立する技法と比喩の峻別

本作の展開構造を音楽理論のフーガ技法と照合したとき、「技法として厳密に一致する部分」と、「概念の比喩的転用に過ぎない部分」を明確に仕分けておく。

① 【厳密な技法的一致】：終幕（p.63）における「ストレット（Stretto / 追迫）」

音楽理論におけるストレットとは、先行する声部が主題を演奏し終わる前に、次の声部が主題頭部を重ねて開始するカノン的追迫技法。
通常、楽曲の終結部で極限の緊迫感を形成するために用いられる。

本作の終幕（p.63）における対話は、このストレットの定義に完全・厳密に合致する。

１「多数決は、」
Ａ「多数決は、」
４「多数が矛盾する。」
Ａ「多数決は破綻する。」

１が発した主題動機「多数決は、」が文末へと解決するのを待たず、時間差でＡが全く同一の動機「多数決は、」を重ねて進入し、さらに４とＡが述語を追迫させていく。
先行フレーズの完了を待たずに同一モチーフを衝突させるこの発話構造は、言語の上演においてストレットの技法が完璧に機能した瞬間となる。

② 【比喩的転用（アナロジー）としての再定義】

以下の3点は、音楽理論の数学的・幾何学的定義そのものではなく、戯曲のプロットを音楽用語になぞらえた比喩 である。

  • 「反行（Inversion）」について:
  • 音楽の厳密な定義: 音程の上昇・下降を軸に対して幾何学的に鏡像反転させる音高操作。
  • 戯曲における実態: 「多数決」という語が持つ機能が、合意形成（正義）からインフラ自滅（破綻）へと反転する物語論的アイロニー。これを「意味の鏡像作用」としてアナロジカルに援用する。
  • 「拡大（Augmentation）／縮小（Diminution）」について:
  • 音楽の厳密な定義: すべての構成音の音価（音の物理的長さ）を等倍で2倍・半分にするリズム操作。
  • 戯曲における実態: 「$0.8^{300}$」という天文学的数字による情報スケールの拡大と、ディキンソンの詩やマスタードが一蹴されて会話が切断される時間的・関係性の縮小。音価ではなく「密度の伸縮」としての比喩とする。
  • 「二重フーガ（Double Fugue）」について:
  • 音楽の厳密な定義: 転回対位法に基づき、上下を入れ替えても和声的に破綻しない2つの旋律が同時に鳴る形式。
  • 戯曲における実態: 「時間の物理的崩壊（NTP/5分/16分）」と「言葉の官僚的脱色（拘束/同行/アノマリー）」という2本の主題的プロットの並走。

③ 【主調回帰なき不可逆性の劇的必然性】

古典フーガは、主調（Tonic）から旅立ち、転調と展開を繰り返した後、最終的に主調へ回帰（再現）して完全終止（Cadence）することで「宇宙的な秩序の回復」を証明する。

しかし『嘘と幻の手順』は、不可逆なエントロピーの増大と管理システムの自滅を描く現代劇です。狂ったNTP（16分の最大誤差）は二度と正しい基準時へは戻らず、朝の光も回復しない。
１の拠って立つ言語が失権し、Ａが自壊する世界をただ凝視する「特等席」を選択した瞬間、劇は主調へ解決することなく、冷たい不協和音を保ったままフェルマータ（静止）して幕を下ろす。
この「主調回帰の拒絶」こそが、古典的調和を解体した現代の対位法劇としての必然的な帰結となる。

4. 上演台本が織りなす「思考のポリフォニー」

『嘘と幻の手順』を対位法（フーガ）として読み解くことで、役者が感情の主旋律（メロディ）を叫ぶことを禁じられ、自立した個体性と機能的態度を持って空間に発声を置くとき、そこには「完全な同時発話であっても観客が立体的に思考を聞き分けられる」という態度派固有のポリフォニー空間の存在可能性が意識できる。

そして、その自立した声部たちが交錯した果てに訪れる「多数決のストレット」と「特等席の非解決終止」――。本作の構造は、言葉が意味を失い自滅していくディストピアの現実を、最も冷徹で厳密な音響・身体の構築物として舞台上に定着させる試みである。
